# Paper Tree Guidelines

These specimen cards capture the foundation of the Paper Tree design system: warm paper surfaces, maroon brand accents, serif academic typography, and restrained software UI.

## Color specimen
- Brand: maroon/plum for primary actions and emphasis.
- Secondary accents: rust and ochre for sparing emphasis.
- Board-tag: red for Previous-Year-Question labels in print material.

## Type specimen
- Serif: Source Serif 4 for headlines, study content, and print-like surfaces.
- Sans: Work Sans for software chrome and form labels.

## Spacing specimen
- Small controls use 4px and 8px radii.
- Cards use 14px corners and soft, low-contrast shadows.

## Brand specimen
- The watercolor tree lockup stays as a considered exception rather than a repeating motif.
- The system favors calm, exact, academic surfaces over lively promotional treatments.

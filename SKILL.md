# Paper Tree Design System

Use this system for academic study-material and assessment software work for Paper Tree.

## Voice and tone
- Write in a precise, academic register.
- Prefer declarative, exact statements over promotional language.
- Use sentence case for headings and UI labels.
- Keep numbers as figures and preserve board-specific brackets like [3 marks, March 2019].

## Visual direction
- Favor warm maroon/plum brand accents on soft cream paper surfaces.
- Use serif typography for study content and sans typography for software chrome.
- Keep interactions restrained: short hover transitions and flat, legible surfaces.
- Reserve the red board-tag color for Previous-Year-Question labels.

## Core tokens
- Brand: maroon/plum.
- Secondary accents: rust and ochre.
- Teal is a sparse contrast accent only.
- Neutrals are warm paper tones and ivory surfaces.

## Shared primitives
- Buttons: primary, secondary, outline, ghost.
- Cards: warm surfaces with light border and soft shadow.
- Tags and badges: compact academic labels.
- Inputs and selects: subtle border treatment with brand focus ring.
- Toasts, dialogs, tooltips, and tabs: calm software UI primitives.
